# NO httpx LINE HERE, ON PURPOSE. config.py builds an httpx client to hand the SDK
# a transport with certificate verification off, so httpx looks like a dependency we
# should name. It is not ours to name. anthropic 0.x imports `httpx`, anthropic 1.x
# imports `httpx2` (httpx 2.x under a new package name), and each one rejects the
# other's client with a TypeError. Whichever the SDK pulls in is the right one, and
# config.py._transport_module() asks it rather than guessing.
