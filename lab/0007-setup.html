What we are building here

Steps

1

Open a terminal

Press ⌘ Space, type Terminal, press Return.

Press the Windows key, type PowerShell, press Enter. Use Windows PowerShell or PowerShell 7 — not Command Prompt.

Check the agent is installed:

claude --version

You should see a version number.

“command not found”? Try this first. Your terminal cannot see the agent, which is a PATH problem rather than a missing install. The prework script sorts it out and tells you what it did:

cd ~/Downloads/vibe-coding-workshop
bash check-prereqs.sh
cd $HOME\Downloads\vibe-coding-workshop
.\check-prereqs.ps1

Then open a new terminal and try claude --version again. Still nothing? 🙋 Raise your card.

2

Get your AWS credentials from the portal

  1. Go to https://ngid.cyberark.cloud/ and sign in with the login on your numbered card 🎟️
  2. Open CYBR User Portal, then click the AWS tile
  3. You land on a page whose address ends in awsapps.com/start/#
  4. Find your account, then click Access keys (some tenants label it Get credentials)
  5. A dialog opens with tabs. Choose your tab:

    → macOS and Linux

    → PowerShell

  6. Under Option 1: Set AWS environment variables, click the copy icon 📋

💡 Notice what just happened. Nobody gave you a permanent AWS key. You asked for access, the platform checked who you are, and handed you credentials that expire. That is zero standing privileges — and you have already used it before we have even explained it.

3

Paste them into your terminal

Click into your terminal window and paste. You will get three lines that look like this — yours will have different values:

export AWS_ACCESS_KEY_ID="ASIA...."
export AWS_SECRET_ACCESS_KEY="....."
export AWS_SESSION_TOKEN="....."

Press Return. Nothing prints. That is success. 🤫

$env:AWS_ACCESS_KEY_ID="ASIA...."
$env:AWS_SECRET_ACCESS_KEY="....."
$env:AWS_SESSION_TOKEN="....."

Press Enter. Nothing prints. That is success. 🤫

⚠️ One terminal only. These values live in this window. Open a second tab and it will not know about them. If you close this window, come back to Step 2.

4

Point Claude Code at Bedrock

Three more lines, in the same window. These tell the agent to use Claude on your company's AWS account instead of a public service:

export CLAUDE_CODE_USE_BEDROCK=1
export AWS_REGION=us-east-1
export ANTHROPIC_MODEL=us.anthropic.claude-sonnet-4-5-20250929-v1:0
$env:CLAUDE_CODE_USE_BEDROCK=1
$env:AWS_REGION="us-east-1"
$env:ANTHROPIC_MODEL="us.anthropic.claude-sonnet-4-5-20250929-v1:0"

Use the Copy button on the block above rather than retyping it — that model name is long and one wrong character produces a confusing error.

5

Go to the folder and switch on your virtual environment 🐍

Move into the workshop folder and activate the virtual environment you made in the prework. This is a fresh window, so it is switched off:

cd ~/Downloads/vibe-coding-workshop
source .venv/bin/activate

Unzipped it somewhere else? Type cd (with the space), then drag the folder from Finder onto the terminal window — it fills in the path for you. ✨

cd $HOME\Downloads\vibe-coding-workshop
.\.venv\Scripts\Activate.ps1

Unzipped it somewhere else? Open the folder in File Explorer, click the address bar, copy the path, and use that after cd. ✨

Your prompt should now start with (.venv). 👀 Then move into the app itself:

cd sandbox-app
cd sandbox-app

Check you are in the right place — you should see summarize.py listed:

ls
dir

And check Python can find the library it needs:

python -c "import boto3; print('boto3 is ready')"

Any of this failing? Try this first. Almost always one of two things. Either there is no (.venv) in your prompt, in which case activate it and you are done. Or you never made one, in which case the prework script builds it and installs the libraries for you:

bash check-prereqs.sh
.\check-prereqs.ps1

Do not install anything globally to get past this. 🙋 Raise your card if the script itself reports something it cannot fix.

6

Start the agent and say hello

claude

The terminal turns into a chat window. Type this and press Return:

In one sentence, what does this app do?

It will read the files around you and answer. 🎉 That is it — you are vibe coding. You did not open a single file yourself.

✅ You are ready when the agent gives you a sentence about summarising incident reports. If it does, wait here — do not run ahead into Lesson 07 until the room is together.

💥 You close the terminal, open a fresh one, and type claude. What happens?

✅ Correct — and this is the single most common problem in the room today. Environment variables belong to one window. New window means redo Steps 2, 3, 4 and 5.

Not this time. We set these with export / $env:, which only affects the current window. Nothing was written to your profile. Try again.
