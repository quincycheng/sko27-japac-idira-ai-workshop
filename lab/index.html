AI Workshop for Idira DC 🎸

First you will build an AI agent out of parts, in five short steps, so nothing about it is mysterious. Then you will point a real one at a real security problem, take that problem away for good — and finish with a demo you can run for a client. No coding experience needed.

  • ⏱️ ~85 min together · ~18 min self-paced
  • 💻 macOS or Windows
  • 🚫 No admin rights needed

👋 Start here. Thirteen lessons, numbered in the order you do them. Part 1 is lessons 01 to 05, where you build an AI harness starting from fifteen lines of Python, so you can see for yourself what an agent is. Part 2 is 06 to 10, where you use a proper one, Claude Code, on Idira problems. Those ten are for everyone. Lessons 11 to 13 are optional advanced courses, so pick one if you finish early and do not worry if you never reach them.

We will run lessons 01, 02 and 05 together as a room. Lessons 03 and 04 are self-paced, which means you read them whenever suits you, including after today. They are written to work that way. 📖

🎯 You are a Domain Consultant, so read every lesson twice. Once as someone learning to use an agent, and once as someone who will be asked to explain this to a customer next month. Part 1 gives you the explanation; Lesson 10 is written specifically as a demo you can reuse, and the last section of it is a script. 🎬

Part 1 · How an AI harness is built 🏗️

Five lessons, five small Python files in ai-harness-app/, each about thirty lines. You run each one, read what it does, then break it on purpose. By the end there is nothing left in the box you have not seen.

Lesson 0N goes with the script called 0N_something.py, so a page and its script never disagree about which step you are on.

  • 01One call to a model ⚛️

    Fifteen lines. A model that talks and cannot act — then find the wall it cannot get past. Everyone · ~8 min

  • 02Give it a tool 🔧

    Hunt six planted secrets yourself, then watch an agent do it. The loop that makes it an agent, line by line. Everyone · ~10 min

  • 03Make it an agent 🧠

    A system prompt, a toolbox, and a hard limit. Ask it to delete everything and watch it fail. Everyone · 📖 self-paced · ~9 min

  • 04Context engineering 📉

    Watch the token count climb until the agent folds its own transcript away. This is what /compact is. Everyone · 📖 self-paced · ~9 min

  • 05When the data lies 🎣

    A file gives your agent orders. Prompts do not save you; nine lines of Python do. Everyone · ~10 min

Part 2 · AI Harness: Claude Code 🎸

Same loop you just built, with better tools — pointed at an app nobody should be proud of.

  • 06Wake up your agent 🤖

    Prove Claude Code works and is talking to Amazon Bedrock. Everyone · ~5 min

  • 07Find the secrets 🔎

    Meet a real-looking app and let Claude review it. It will not like what it finds. Everyone · ~13 min

  • 08Zero standing privileges 🎫

    Hold no AWS access at all — then use a skill to ask Idira for it, briefly. Everyone · ~10 min

  • 09Delete the key ✂️

    Make the app work with no credentials in it — and say out loud what is still unfixed. Everyone · ~8 min

  • 10The Identity Broker 🛡️

    Give an agent access to a tool while it holds no credential — then watch one click cut off the whole room. Everyone · ~12 min

Before you start ✅

You should already have all of this from the prework:

  • 📦 The workshop folder unzipped somewhere you can find again
  • 🐍 A virtual environment in that folder, with boto3 and anthropic installed — and you know the command to activate it
  • 🤖 Claude Code — claude --version prints a number
  • ⌨️ idsec — idsec version prints a number, and you have run idsec configure once
  • 🔐 AWS access — you can reach the AWS tile in the portal and see an Access keys link
  • 🎟️ Your numbered card with your login on it

Missing something? Run the prework script first. It checks every item on that list, fixes most of them, and tells you plainly which ones it cannot:

# macOS
cd ~/Downloads/vibe-coding-workshop
bash check-prereqs.sh

# Windows PowerShell
cd $HOME\Downloads\vibe-coding-workshop
.\check-prereqs.ps1

Then don't sit quietly about whatever is left. 🙋 Hold up your numbered card and a helper will come to you. It is faster to fix now than in twenty minutes.
